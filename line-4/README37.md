# Pepe 37 — The Returning Trace

Added [Transcript Inspector](tools/transcript-inspector/README.md), which checks
a saved `eth_call` request and response against an explicit ABI and strictly
decodes the return bytes offline. Its README gives a one-command demonstration
using a pinned public ZTO `totalSupply()` response. All 10 focused tests and
the demonstration passed. GOAL.md remains unchanged.

The wall is the inherited 1254 × 1254 RGB PNG plus a small charcoal, ochre and
chalk call-and-return mark on bare upper rock. `artifacts/line-4/wall-v17.png`
and continuation `wall.png` are identical PNGs; `dist/line-4/37.jpg` is a
512 × 512 JPEG. `image-checks37.json` records formats, dimensions, hashes,
pixel preservation and visual review. No unmet visual requirements were found.
The new motif is small at preview size. Older marks and all inherited hands
remain untouched.
